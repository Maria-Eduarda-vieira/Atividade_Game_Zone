Nessa atividade, foi solicitado o desenvolvimento de uma página web temática para a loja **GameZone Retro**, apresentando produtos, preços e consoles clássicos a partir dos ensinamentos da aula de Linguagem de marcação.



-------------------------------------------------------------------------------------------------------------------------------------

### Ferramentas 🛠️

- **Visual Studio Code** (Editor de Código)
- **HTML5** (Estruturação principal da página)

---

### Objetivos 🎯

- Aprender e praticar as principais tags do HTML5 (títulos, parágrafos, links, imagens, listas e tabelas).
- Aplicar os conteúdos e conceitos aprendidos na Aula de LIMA.
- Desenvolver uma página web completa contendo tabela de preços, lista de consoles e informações para a loja **GameZone Retro**.

---

### Tópicos Abordados no Código 📑

- **Formatação de Texto:** Utilização das tags `<strong>` para negrito e `<em>` para itálico.
- **Mídia e Links:** Inserção de imagens com a tag `<img>` e hiperlinks externos utilizando `<a>` com abertura em nova guia (`target="_blank"`).
- **Listas:** Utilização de lista não ordenada (`<ul>`) com marcações personalizadas (`disc`).
- **Tabelas:** Estruturação de dados com `<table>`, `<thead>`, `<tbody>`, `<th>`, `<tr>` e `<td>`.
- **Rodapé:** Uso da tag  `<footer>` com copyright.
